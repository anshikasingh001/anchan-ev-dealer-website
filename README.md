# Anchan EV Website

A modern and responsive dealership landing page developed for **Anchan EV** to showcase dealership opportunities and collect customer enquiries. The website features a professional UI, a fully functional enquiry form, Google Sheets integration, and automatic email notifications using Google Apps Script.

## Features

- Responsive and modern design
- Dealer enquiry form
- Google Apps Script backend
- Google Sheets data storage
- Automatic email notifications
- Deployed with Netlify using a custom domain

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Sheets
- Netlify
